# AbysaCompiler
AbysaCompiler - the best compiler with AI ever

This compiler has hidden AI, to use it you need to write //ai <ur prompt> and + tab
Unfortunately compiler work only for CPP(

This compiler also has functions such as:

  msv + tab - creation an array
  mtx + tab - creation of a matrix
  comand + P or ctrl + P - works like Prettier in VS code 
  "#" + tab - creation of base code
  
More cool features are coming very soon...
